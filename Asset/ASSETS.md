# AgentPong — ассеты агента

## agent/ — актуальный визуал

| Путь | Что это |
|---|---|
| `icon.png` | иконка приложения (вкладка, окно, трей) |
| `icon.ico` | иконка ярлыка Windows (16/32/48/256 из icon.png) |
| `office.png` | фон виджета: офис с монитором (рабочее место Понга) |
| `source/*.jpeg` | исходные спрайт-листы 2×2 (1024×1024, фон белый) + `office.jpeg` — не трогать, эталон для пересборки |
| `frames/*.png` | рабочие кадры 512×512, нарезка листов, фон прозрачный |

Пайплайн нарезки: `node tools/sprites-cut.cjs` — режет каждый лист 2×2 на 4
кадра и глушит белый фон BFS-заливкой от краёв (внутренние белые зоны,
например шар-голова, не затрагиваются).

Порядок кадров: слева-направо, сверху-вниз → `файл -1..-4.png`.

## frames/ — 11 настроений (44 кадра)

| mood | Настроение | Панель на листе |
|---|---|---|
| happy | весёлый, подмигивает, «класс» | 1 |
| think | задумчивость, чешет подбородок | 2 |
| eureka | размышление → «эврика», палец вверх | 3 |
| shock | изумление, отвисла челюсть | 4 |
| scheming | жадно потирает руки | 5 |
| mocking | ехидно ухмыляется | 6 |
| bored | зевает, подпирает щеку | 7 |
| angry | возмущение, размахивает руками | 8 |
| search | поиск, рука ко лбу, смотрит по сторонам | 9 |
| laugh | хохочет, держась за живот | 10 |
| busy | занятый: суетится с бумагами/инструментами | 11 |

Использование: `ui/js/emotions.js` — карта «событие → настроение», каждая
эмоция — петля из 4 кадров (main.js, `playEmotion` ≈6.7 к/с на ~2.6 с),
idle — медленная петля happy (~2 к/с).
