# AgentPong 🏓

Агент-навигатор для глобальной сети на собственном протоколе **HTTPR** (v6.4+).
Продолжение идей В. М. Глушкова: сеть из того, что уже есть; нервная система,
а не склад.

## Что это

- **Ядро HTTPR** — всёядный конвертный протокол поверх HTTPS/HTTP: слепые конверты,
  дедупликация, фрагментация, TTL, переживает смерть любого узла (включая свои серверы).
- **Исчезающий мессенджер** (первая шкура, наследие RobinHood P2P) — одноразовые
  сеансы связи: создатель канала чистит сессию у всех участников, ничего не остаётся.
- **Агент-навигатор** (цель проекта) — вопрос-конверт прыгает от узла к узлу
  (пин-понговый шарик), собирает подписанные, свежие ответы от живых узлов и
  указатели на открытые библиотеки знаний. Ничего не копит: задача — быстро
  ориентироваться в глобальном пространстве, а не хранить его.

## Принципы (неизменяемый слой — не патчится консенсусом сети)

1. **Не навреди.** Код агента не исполняется на узлах: узлы отвечают на вопросы,
   но не выполняют чужие инструкции.
2. **Сеть — из того, что уже есть.** Бесплатные хостинги, домашние компьютеры,
   локальный Wi-Fi, мобильный интернет — это равноправные «пути» одного протокола.
3. **Никаких привилегий от рождения.** Сервер — это узел с высоким uptime,
   а не начальник. Любая нода: ящик + почтальон + участник.
4. **Ноль рублей.** Протокол обязан жить на бесплатной инфраструктуре и устройствах
   участников. Компромисс бесплатности — это спецификация, а не недоработка.
5. **Ноль памяти по замыслу.** Мессенджер исчезает, навигатор не копит.
   Вечным должно быть только ядро и принципы.

## Состав репозитория

| Файл | Роль |
|---|---|
| `p2ppong.js` | ядро HTTPR: рукопожатие (X3DH), рatchet (sym + DH), конверты, пути, WebRTC |
| `crypto-worker.js` | вся криптография (Web Crypto в Web Worker): ECDH P-256, AES-256-GCM, HMAC, HKDF |
| `worker.js` / `server.js` | референсные узлы-ящики (Cloudflare Worker / Node) — семечки первой встречи |
| `test-ratchet.js` | регрессионные тесты ядра (25 сценариев): node test-ratchet.js |
| `PROTOCOL.md` | спецификация HTTPR / AgentPong |
| `ROADMAP.md` | план движения к агенту |
