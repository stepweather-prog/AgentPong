# AgentPong 🏓

Умный агент на бесплатных мощностях: локальные мозги (web-llm на твоей
видеокарте) + бесплатные облачные API (GLM-Flash от Z.ai и другие
OpenAI-совместимые). Ноль рублей за всё, ноль хранения твоих данных.

## Что это

- **Агент-виджет** — живое окно с характером (скупой на слова, щедрый на
  помощь, сарказм бесплатно), голосом и руками (звук, запуск приложений
  по белому списку, статус железа).
- **Три мозга на выбор**: правила (оффлайн, мгновенно), локальная LLM
  (web-llm, разовая закачка весов — потом без сети), облачный адаптер
  для любого OpenAI-совместимого API.
- **Команды-жесты** перехватываются до мозга: работают без сети и токенов.
- **Приватность**: история реплик только в памяти сеанса, ключи API —
  только на твоей машине.

## Состав репозитория

| Файл | Роль |
|---|---|
| `ui/` | вся сцена агента: спрайты, газетенки, мозги, голос |
| `electron/` | Electron-оболочка виджета (трей, TTS, руки) |
| `Asset/` | картинки агента и интерфейса |
| `p2ppong.js` | экспериментальный сетевой модуль (в разработке, агент от него не зависит) |
| `crypto-worker.js` | криптография сетевого модуля |
| `test-ratchet.js` | регрессионные тесты сетевого модуля: node test-ratchet.js |

## Запуск

- Виджет: ярлык из `tools/` или `npx electron .`
- Браузер: любой статик-сервер на корень репы (например `npx serve .`),
  открыть `ui/`
